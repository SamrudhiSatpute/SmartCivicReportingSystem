A web portal where citizens can report issues with details, location, and photos, tracked in real-time Key features: 
Location-based reporting for accurate tracking Photo upload for verification, 
Real-time dashboard for authorities to resolve issues quickly. Citizen reward system to encourage participation, 
Admin tools to manage and monitor complaints efficiently. 
Impact: The system speeds up response times, enhances transparency, and encourages citizen engagement. 
By integrating technology into civic management it helps the city develop faster into a smart, 
safe, and sustainable urban space.
TechStack:
 Backend:SpringBoot
 Frontend:React
 Database:MySQL
